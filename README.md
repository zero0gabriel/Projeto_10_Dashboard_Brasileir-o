# ⚽ Dashboard de Análise de Clubes de Futebol

Projeto desenvolvido em Python com o objetivo de organizar, visualizar e analisar dados de clubes de futebol ao longo de diferentes temporadas.

O dashboard permite explorar informações por meio de gráficos interativos, tabelas, indicadores e filtros de clubes e temporadas, facilitando a comparação dos dados e a identificação de padrões.

## 📊 Funcionalidades

* **Geral:** visão geral dos dados, com indicadores e gráficos.
* **Desempenho:** análise dos resultados esportivos e da classificação dos clubes.
* **Financeiro:** comparação dos valores dos elencos entre temporadas.
* **Elencos:** exploração de informações sobre a composição dos times.
* **Qualidade dos Dados:** identificação de dados ausentes, duplicados e possíveis inconsistências.

## 🛠️ Tecnologias utilizadas

* Python
* Pandas
* Streamlit
* Plotly

## 🎯 Objetivo do projeto

Praticar programação em Python e desenvolver habilidades de análise e visualização de dados, utilizando o futebol como contexto para transformar dados em informações mais fáceis de interpretar.

**Status:** projeto educacional em desenvolvimento.
